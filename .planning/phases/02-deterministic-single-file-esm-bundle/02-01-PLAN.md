# Plan 02-01: Exact tsdown Build and Generated-Output Policy

## Objective

Add the deterministic single-file build command without changing source package exports or deleting other `dist/` products.

## Tasks

1. Add a maintained `tsdown.config.ts` or equivalent build script using `src/index.ts`, browser ESM, `esnext`, one entry, no splitting, no externals, no declarations, and deterministic naming.
2. Add `build:mjs-bundle` and ensure output preparation only removes/replaces `dist/esnext.bundle.mjs`.
3. Add `dist/` to `.gitignore` after preserving existing unrelated rules; do not commit generated files.
4. Confirm the reachable source graph excludes tests, planning, scripts, working example, examples, and fixtures.

## Must Haves

- Exact filename and no secondary chunks.
- Bookmarklet artifacts in `dist/` survive a bundle rebuild.
- `package.json` exports still resolve to `src/index.ts`.

## Verification

Run the build twice from a controlled output state and compare output inventory and bytes. Inspect package exports and ignored-file behavior.
