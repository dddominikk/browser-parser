# Plan 02-02: Bundle Validation and Import Smoke Tests

## Objective

Make bundle correctness observable and portable in local and CI validation.

## Tasks

1. Add a Node-side bundle validation script/test for exact output, one file, no TypeScript or unresolved relative imports, and expected public exports.
2. Add repeated-build determinism coverage with stable output comparison and no timestamp assumptions.
3. Add an import smoke test that imports the bundle as an ESM module and verifies capture, registry, and built-in parser exports.
4. Add a regression test proving existing bookmarklet files are not removed when present in `dist/`.

## Must Haves

- Tests fail on extra chunks or missing public exports.
- Smoke validation tests the actual generated artifact rather than source files.

## Verification

Run `npm run build:mjs-bundle`, the focused bundle tests, and full `npm run validate` after Phase 1 is available.

## Dependencies

Plan 02-01 and Phase 1's exported capture contract.
