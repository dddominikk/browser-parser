# Plan 03-01: Shared Bookmarklet Generator and Dual Loaders

## Objective

Replace duplicated inline bookmarklet source with deterministic public and private generated artifacts.

## Tasks

1. Extract shared generator/template logic for report-window setup, status rendering, popup handling, export validation, capture invocation, and import errors.
2. Add `build:public-ts-bookmarklet`, derive repository owner/name from package metadata, and emit `dist/public-bookmarklet.js` with the existing esm.sh URL.
3. Add `build:private-gist-mjs-bundle-bookmarklet`, validate configured gist data, construct the raw URL, and emit the fetch/response/text/Blob/object-URL loader.
4. Decide and document the root `bookmarklet.txt` compatibility handling so it is generated or removed, never independently maintained.
5. Add tests for single-line format, deterministic output, synchronous `window.open`, correct loader, popup behavior, export validation, configuration changes, and all private loader failures/object-URL revocation.

## Must Haves

- No captured page data is embedded in generated source.
- Private output fails early when configuration is malformed.
- Import/load failures update the already-open report tab.

## Verification

Run both build commands and inspect artifacts for one line, `javascript:` prefix, no TypeScript syntax, and expected loader strings without exposing a private URL in logs.

## Dependencies

Phase 2 exact bundle contract and the existing report-surface API.
