# Plan 04-01: CI, Hygiene, and Documentation

## Objective

Make the public build reproducible and explain the migration from public source loading to private bundle loading without leaking secrets.

## Tasks

1. Add the main-branch/manual-dispatch workflow with supported Node setup, `npm ci`, validation, bundle build, chunk assertion, smoke test, and public bundle artifact upload.
2. Add concurrency cancellation if compatible with repository conventions and ensure no deploy/push/private artifact steps exist.
3. Remove only the `.gitignore` conflict markers and add `dist/` while preserving unrelated rules and worktree files.
4. Update README and relevant docs with result shape, cookie/CSP/popup limitations, both bookmarklet commands and outputs, gist configuration/deployment, repository visibility gate, and installation instructions.
5. Replace any duplicated root bookmarklet prose/source with a generated-artifact reference consistent with Phase 3.

## Must Haves

- Public CI cannot expose the private raw URL or private bookmarklet.
- Docs do not claim unsupported browser/privacy behavior.

## Verification

Parse the workflow, run the equivalent local commands, scan tracked/public files for secret URL patterns, and review documentation against actual script names and artifact paths.
